Dissenyat per a la IA: arquitectura MCP

MCP (Model Context Protocol) és l'estàndard obert amb què els assistents d'IA fan servir les eines d'altres programes. IAQ Gest ofereix més de 80 eines per MCP, així que cada membre de la junta connecta el seu propi assistent al seu compte i gestiona l'associació conversant.

Cada eina té un de tres nivells —lectura, escriptura o proposta— i l'assistent només pot fer el que permet el càrrec de qui n'és propietari.

👤

Cada persona, el seu assistent

Connecta el seu assistent d'IA (Claude, ChatGPT, Gemini, Copilot, Cursor, agents propis) al seu compte.

🔑

Clau personal revocable

Cada persona té la seva clau (revocable i amb caducitat) i l'assistent actua amb els permisos del seu càrrec: tresoreria només veu economia.

🔒

Propostes per a les accions importants

Cobrar una remesa, esborrar o publicar queden com a propostes que la persona aprova amb un clic.

🔍

Mai no veu dades sensibles

DNI/NIE/NIF, IBAN i similars es filtren automàticament abans d'arribar al model.

🔗

Connexió amb Claude.ai i ChatGPT per OAuth

Connexió segura i privada amb un codi d'un sol ús.

📊

Registre d'activitat i accés remot

Accés segur amb Tailscale i registre de tota l'activitat de l'agent.

Connecta'l en un minut

Servidor MCP per HTTP per a Claude.ai i ChatGPT, pont stdio per a Claude Desktop o Cursor, i descripció OpenAPI 3.1 per a qualsevol altre agent. Exemple per a Claude Desktop o Cursor:

{
  "mcpServers": {
    "iaraque-gestio": {
      "command": "node",
      "args": ["scripts/mcp.ts"],
      "env": { "IARAQUE_URL": "http://127.0.0.1:3000", "IARAQUE_CLAU": "iaq_..." }
    }
  }
}

Preguntes freqüents

És realment gratuït?

Sí, IAQ Gest és completament gratuït i de codi obert, amb llicència MIT.

Cal saber d'IA o d'informàtica?

No. S'instal·la com qualsevol altre programa i un assistent et guia en començar. Connectar el teu assistent d'IA és opcional i el programa t'explica pas a pas com fer-ho.

El puc fer servir sense assistent d'IA?

Sí. IAQ Gest és un programa complet amb la seva pròpia finestra; l'assistent d'IA és una manera més de fer-lo servir, no un requisit.

L'assistent pot veure els DNI o els comptes bancaris?

No, les dades sensibles com DNI/NIE/NIF i comptes bancaris es filtren automàticament per protegir la privadesa.

En quins idiomes funciona?

En català, castellà i anglès: el programa, l'instal·lador, l'assistent inicial i el manual d'ajuda. Cada persona tria el seu idioma i el programa el recorda.

On es desen les dades?

Les teves dades es desen al teu ordinador i no s'envien al núvol sense el teu consentiment explícit.

El puc fer servir des de casa?

Sí, pots fer servir IAQ Gest des de casa gràcies a Tailscale: cada membre de la junta es connecta a l'ordinador de l'associació per una xarxa privada, sense obrir-lo a internet. L'ajuda del programa ho explica pas a pas.
